Welcome to the Competitive Programming Judge (CPJ) API documentation.

== Global Configurations & Authentication

Most API requests require authentication. Requests are validated via custom interceptors.

=== Request Headers
All authenticated endpoints require the session token in the **`X-Roll-No`** header:
* `X-Roll-No`: Active session token (e.g., `STU-SESSION-...` or `ADM-SESSION-...`).

Alternatively, the token can be passed as a query parameter: `?rollNo=<token>`.

=== Admin Login
Logs in an administrator using their password configured in application properties.

* **Path**: `/api/admin/login`
* **Method**: `POST`
* **Security**: Public

==== Request Payload Example
[source,json]
----
{
  "username": "admin",
  "password": "secretPassword"
}
----

==== Response Payload Example
[source,json]
----
{
  "token": "ADM-SESSION-8ac2...",
  "user": {
    "username": "admin",
    "name": "Super Admin",
    "role": "ADMIN"
  },
  "userType": "admin"
}
----

== Contest API (Public/Student)

=== List All Contests
Retrieves a list of all contests in the system.

* **Path**: `/api/contests`
* **Method**: `GET`
* **Security**: Authenticated (Student/Admin)

==== Response Payload Example
[source,json]
----
[
  {
    "id": 1,
    "title": "Welcome Challenge",
    "description": "Getting started challenge",
    "startTime": "2026-06-18T10:00:00Z",
    "durationMins": 60,
    "status": "ENDED"
  }
]
----

=== Record Cheating Violation
Increments or updates the tab-switch/cheating violation count for a student in a contest. If the count reaches 3, the workstation is locked.

* **Path**: `/api/contests/{contestId}/students/{rollNumber}/violation`
* **Method**: `POST`
* **Security**: Authenticated (Student/Admin)

==== Request Body
[source,json]
----
{
  "violations": 3
}
----

==== Response Body
[source,json]
----
{
  "success": true,
  "violations": 3,
  "status": "Locked"
}
----

=== Get Contest Workstations
Retrieves all workstation statuses (active or locked due to violations) for a specific contest.

* **Path**: `/api/contests/{contestId}/workstations`
* **Method**: `GET`
* **Security**: Authenticated (Admin only)

== Student Info API

=== Get Registrations
Retrieves all contests a student is registered in and their participant statuses/violations.

* **Path**: `/api/students/{rollNumber}/registrations`
* **Method**: `GET`
* **Security**: Authenticated (Student/Admin)

=== Reset Student Violations
Resets tab-switching violation counts to 0 and unlocks the workspace for a student across all active contests.

* **Path**: `/api/students/{rollNumber}/reset-violations`
* **Method**: `POST`
* **Security**: Authenticated (Admin only)

---

== Live Event SSE API

=== SSE Live Leaderboard
Exposes a Server-Sent Events (SSE) stream that broadcasts updated leaderboard rankings whenever submissions are evaluated or violations occur.

* **Path**: `/api/events/leaderboard`
* **Method**: `GET`
* **Security**: Public

== Admin Contest Management API

=== Create Contest
Creates a new contest.

* **Path**: `/api/admin/contests`
* **Method**: `POST`
* **Security**: Authenticated (Admin only)

=== List Contests
Lists all contests with full administration details.

* **Path**: `/api/admin/contests`
* **Method**: `GET`
* **Security**: Authenticated (Admin only)

=== Get Contest Detail
Gets detailed information about a contest, including assigned problem IDs.

* **Path**: `/api/admin/contests/{id}`
* **Method**: `GET`
* **Security**: Authenticated (Admin only)

=== Start Contest
Forces a contest to start immediately, changing its status to `ONGOING`.

* **Path**: `/api/admin/contests/{id}/start`
* **Method**: `POST`
* **Security**: Authenticated (Admin only)

=== End Contest
Forces a contest to end immediately, changing its status to `ENDED`.

* **Path**: `/api/admin/contests/{id}/end`
* **Method**: `POST`
* **Security**: Authenticated (Admin only)

=== Update Contest
Modifies contest parameters (title, description, duration, and assigned problem list).

* **Path**: `/api/admin/contests/{id}`
* **Method**: `PUT`
* **Security**: Authenticated (Admin only)

=== Delete Contest
Removes a contest and its mappings.

* **Path**: `/api/admin/contests/{id}`
* **Method**: `DELETE`
* **Security**: Authenticated (Admin only)

=== Get Contest Submissions
Retrieves all submissions made by all students for a specific contest.

* **Path**: `/api/admin/contests/{id}/submissions`
* **Method**: `GET`
* **Security**: Authenticated (Admin only)

=== Get Contest Registrations
Retrieves all students currently registered for the contest.

* **Path**: `/api/admin/contests/{contestId}/registrations`
* **Method**: `GET`
* **Security**: Authenticated (Admin only)

=== Register Students Bulk
Registers multiple students to a contest by passing their roll numbers in a JSON Array.

* **Path**: `/api/admin/contests/{contestId}/registrations`
* **Method**: `POST`
* **Security**: Authenticated (Admin only)

=== Delete Student Registration
Removes a student's registration from a contest.

* **Path**: `/api/admin/contests/{contestId}/registrations/{userId}`
* **Method**: `DELETE`
* **Security**: Authenticated (Admin only)
